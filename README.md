# Ordering Marketplace

Run your Ordering marketplace locally with your own project and make your first visible change.

## 1. Paste this into your coding agent

```text
Get https://github.com/Ordering-co/website-marketplace.git, reusing any existing checkout. Read setup.md and follow it to connect my confirmed Ordering project, start the marketplace, and show one simple visible edit. Preserve my changes.
```

## 2. Confirm your project

Confirm the project your agent identifies, or ask it to help you use a different one.

## 3. Open your marketplace

Open the local link your agent gives you. Check the selected project and catalog, then ask for a small text change and watch it update.

Local development: macOS or Linux; Windows through WSL.
