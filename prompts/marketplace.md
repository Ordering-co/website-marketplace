# Website Marketplace prompts

## Connect and start

```text
Get https://github.com/Ordering-co/website-marketplace.git, reusing any existing checkout. Read setup.md and follow it to connect my confirmed Ordering project, start the marketplace, and show one simple visible edit. Preserve my changes.
```

## Diagnose

```text
Read setup.md and docs/marketplace-troubleshooting.md. Diagnose my Website Marketplace environment, selected project, effective public configuration, permissions, catalog requests, socket, CORS and port. Preserve my files and existing servers. Use only read requests and report observed evidence without secrets or personal data.
```

## Personalize

```text
Follow docs/marketplace-first-edit.md and make the local preview label say My first Marketplace edit. Show before/after and verify hot reload and the unchanged project. Edit presentation only, preserve the shared submodule and make no project-data writes.
```

## Update

```text
Read the update section in docs/marketplace-troubleshooting.md. Verify the approved version and checksum, preserve my current code and configuration in a recoverable copy, compare the new source, merge my presentation changes, and verify tenant/catalog and rendering before switching. Do not publish, deploy, overwrite my directory or reset my Git history.
```

## Reconnect or disconnect

```text
Read setup.md and offer the project detected from my existing Ordering connection. If I choose another project, check browser project-only selection capability and take its result automatically when available. If unavailable, explain the pending release and offer the explicit public-project fallback without claiming membership. Never create keys or ask again for a project identifier already detected. Validate public configuration before applying --reconnect, keep backups and my previous consumer session. If I ask to stop, stop only this preview and preserve developer connections.
```
